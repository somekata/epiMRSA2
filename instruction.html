1. すぐ使う

  1. 左上「CSV読み込み」からファイルを選択
  2. または「サンプルCSVを読む」 → data/mrsa_sample_100records.csv
  3. 期間/病棟/施設フィルタを設定し「解析を更新」
  4. Overview → Trend → Profile → Signals の順で見ると理解しやすい

2. CSV仕様

2.1 必須列

collection_date, ward, hospital, specimen, POT1, POT2, POT3
2025-01-14, ICU, OMU, blood, 106, 77, 113

2.2 任意列（入っていれば活用）

  • onset_type
  • patient_id
  • clindamycin_R（0/1）
  • vancomycin_MIC, daptomycin_MIC

2.3 欠損の扱い

  • ward/hospital/specimen 欠損 → "unknown"
  • collection_date 欠損 → 時系列解析から除外

3. 各タブの機能

Upload / Settings

CSV読み込みとフィルタ設定（全タブ共通）

Overview

  • 分離数・ユニークPOT
  • 病棟別棒グラフ
  • 検体Pie
  • 月別総件数

POT Trend

上位5 POTの月別推移を折れ線で表示。

POT Profile

  • POT×病棟ヒートマップ
  • POTカード（Ward/Specimen/Onsetの最多カテゴリ）
  • 耐性率・MIC分布
  • 自動ラベル：ICU侵襲型、市中救急型など
  • 類似POT（cosine距離）

Signals

POT × 病棟ごとに、短期間での集積（k件以上）を sliding-window方式で検出。

Raw Table

POT / 病棟 / 検体 / patient_id で検索可能。

4. Signal（アウトブレイク芽）の原理

  1. POT × 病棟ごとに分離日でソート
  2. 右端を増やしつつ、左端が窓幅を超えたら進める
  3. 窓内件数が閾値に達したら signal として登録

※ 伝播の“動線”はタイムラインの重なりで把握。

5. 類似POTの仕組み

POTごとに以下の情報をベクトル化：

  • Ward 分布
  • Specimen 分布
  • onset_type 分布
  • CLDM-R率、VCM≥2、DAP≥1

cosine similarity > 0.65 を「類似POT」と表示。

6. よくある質問

  • POT番号の意味付け → Profileタブの自動ラベルを参照
  • Signalが出ない → 窓幅を広げる / 閾値を下げる
  • Signalが多すぎる → 先に病棟・期間を絞る
  • 日付形式は？ → yyyy-mm-dd 推奨（JSで自動判定）
